● Good questions. Those were arbitrary defaults, not firm recommendations.

  ChromaDB vs Qdrant:

  ┌─────────────┬────────────────────────┬──────────────────────────────────┐
  │             │        ChromaDB        │              Qdrant              │
  ├─────────────┼────────────────────────┼──────────────────────────────────┤
  │ Setup       │ Zero-config,           │ Requires server (Docker)         │
  │             │ in-process             │                                  │
  ├─────────────┼────────────────────────┼──────────────────────────────────┤
  │ Persistence │ SQLite-backed          │ Native binary format             │
  ├─────────────┼────────────────────────┼──────────────────────────────────┤
  │ Scale       │ Good for <1M vectors   │ Better for large scale           │
  ├─────────────┼────────────────────────┼──────────────────────────────────┤
  │ API         │ Simpler Python API     │ More features (filtering,        │
  │             │                        │ payloads)                        │
  └─────────────┴────────────────────────┴──────────────────────────────────┘

  For this assignment (small dataset, local dev), either works. Qdrant is better
   if you want production-ready infrastructure from the start.

  Claude Sonnet vs Gemini:

  ┌───────────────────┬─────────────────────┬─────────────────────────────┐
  │                   │    Claude Sonnet    │      Gemini 2.0 Flash       │
  ├───────────────────┼─────────────────────┼─────────────────────────────┤
  │ Cost              │ ~$3/1M input tokens │ Free tier (15 RPM)          │
